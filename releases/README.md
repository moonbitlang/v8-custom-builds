# Native release notes

Each release has a `v0.106.0-moonbit.N.md` file describing its changes, host-visible
behavior and limitations. Historical notes describe the release at that time;
they are not substitutes for the current API documentation.

- [.2](v0.106.0-moonbit.2.md)
- [.1](v0.106.0-moonbit.1.md)

Write the notes alongside each release-pin change, and update them before tagging.
Publication reads the notes from that tag, not from a later checkout, and appends
qualification/provenance links. A notes file does not authorize a release.
