# v0.106.0-moonbit.7

This release adds cross-thread execution termination and a prepared native path
for typed numeric calls. It does not change the V8 revision or Wasm feature policy.

- `Store::interrupt_handle()` returns a cloneable `Send + Sync` handle. It uses
  V8's termination/cancellation mechanism and safely returns false after store
  destruction. It does not keep the store alive or make other handles thread-safe.
  Interrupted calls and start functions report `Error::Terminated`, distinct from
  ordinary traps and catchable Wasm exceptions. Blocking host callbacks still
  require the host to unblock them.
- Typed numeric exports prepare the existing V8 C-to-Wasm entry once and pack
  numeric values directly into its native buffer. Repeated calls skip C API
  arity checks, reference scans and signature-driven conversion. V8 execution,
  GC, trap handling, and Rust memory-borrow/re-entry checks remain in place.
  Direct host-function exports continue through their callback conversion path.
- Release notes are versioned here. Publication requires notes from the tagged
  commit and appends the consumer qualification link and archive provenance.

The Rust wrapper requires the matching `.7` archive and header, with no
older-release fallback. The standard `wasm.h` interface is unchanged; additions
are in `wee8.h`. Embedders matching every `Error` variant must handle the new
`Terminated` variant. This change does not alter Moon's runtime default.

Performance measurements and five-platform validation are required before this
candidate can be published. See the associated PR for its validation status.
